# 诗语映画 · 产品交互原型

基于 Next.js、React、TypeScript 的国风知识动画网站原型，兼容电脑与手机。

## 本地运行

要求 Node.js 20.9+，建议使用 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器访问 http://127.0.0.1:3000 。

## 体验路径

1. 首页输入“静夜思”或“守株待兔”，点击生成动画。
2. 输入测试手机号，例如 `13800138000`，点击获取验证码。
3. 使用 `123456` 登录；不会发送真实短信。
4. 约 8 秒后模拟制作完成，可查看模板动态预览、下载演示说明。
5. 进入我的作品查看历史记录、删除作品，或退出后切换另一个测试账户。

## 原型边界

- 登录为浏览器端演示，验证码有效期及重新获取间隔均为 60 秒。不是生产认证，不提供真实账户安全性；请勿使用真实手机号或私人内容。
- 作品按测试手机号保存在本机 localStorage，登录状态在 sessionStorage。该分组仅展示账户体验，不能替代服务器授权。
- 进度为定时器模拟，刷新或关闭页面会中断当前制作；已完成记录保留。
- 动态预览是预置 SVG 插画的镜头运动和字幕切换，无真实配音、AI 图像生成或 MP4 输出。下载内容明确为 TXT 演示说明。
- 任意输入仅演示交互，不核实内容。默认分类为演示规则，非生产知识识别。
- 设置可切换，但未绑定真实渲染。未接入短信服务、数据库、对象存储、任务队列和 AI API。
- 首页和灵感画廊公开；创作与个人作品在交互层需要登录。
- 原创代码绘制的 SVG 图用于示意，不代表最终绘本动画画质。

## 验证

```sh
npm run typecheck
npm run build
npm test
```

浏览器测试使用本机 Microsoft Edge；包含登录错误、验证码失效、制作流程、下载、刷新恢复、账户分组、删除、手机布局与预览交互。
Windows 项目约束验证：`powershell -File tests/Test-Agents.ps1`。

## 后续服务接入

1. 将演示登录替换为短信服务 + 服务端 session / HttpOnly cookie，添加发送与验证限流、错误次数限制。
2. 创建任务和作品 API；服务端根据会话检查用户归属，禁止客户端决定身份。
3. PostgreSQL 保存用户、知识条目、任务和分镜，Redis + BullMQ 调度后台 Worker。
4. 接入文本、图片、配音服务；FFmpeg 制作真实视频，S3 兼容存储保存素材和输出。
5. 进度改为服务端持久状态，增加失败重试、预算限制和断点恢复。
6. 完成真实端到端检查后发布 GitHub 仓库及服务器部署。

## 主要文件

- `app/page.tsx`：创作工作台与弹窗、演示状态流。
- `app/globals.css`：响应式样式与动态分镜效果。
- `public/*.svg`：本地原创示例插画。
- `tests/browser/prototype.spec.ts`：交互回归测试。

当前交付仅为本地原型，未发布外部网站或 GitHub 远程仓库。
